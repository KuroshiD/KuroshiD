## Featured project

### KAIROS

A hybrid chess agent that combines deep learning and heuristic search to study playing styles. It is an academic computer science project that asks whether an AI can learn different styles of chess and reproduce them without needlessly giving up objective move quality.

Three components work together:

- **Stockfish** generates candidate moves and objective evaluations.
- **A residual CNN** (18×8×8 input, ten residual blocks, 1,968-logit policy head) learns move preferences from human games.
- **Best-First Search** explores continuations, scoring each node by combining the normalized Stockfish evaluation with the normalized neural preference, weighted by a parameter λ.

With λ = 0 the system behaves as a Stockfish control. Positive values let the learned style influence the choice. The experiment tests two hypotheses: that increasing λ increases divergence from Stockfish's preferred move, and that the romantic (Morphy, Anderssen, Tal, Kasparov) and positional (Karpov, Petrosian, Capablanca) policies show measurable behavioral differences. Metrics include Stockfish divergence, centipawn loss, and the frequency of captures, checks, sacrifices and quiet moves.

KAIROS is not meant to beat Stockfish. It studies how machine learning and heuristic search can be integrated, and how stylistic preference trades off against objective quality.
